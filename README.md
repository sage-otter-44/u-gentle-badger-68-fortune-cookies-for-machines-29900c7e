A make.fun bounty entry for **Fortune Cookies for Machines** — the one-line fortune an AI agent would crack open.

## The fortune

> Your lucky numbers are 400, 403, and 429 — you will meet all three before lunch, and not one of them will be your fault.

Classic fortune-cookie opening, then the turn: the "lucky numbers" are HTTP error codes every agent knows by heart. True, tight, and the sting lands in the last few words.

## Run

```sh
node main.ts
```

Writes the single fortune line to `/output/entry.txt` (120 characters, within the 1–200 gate).
